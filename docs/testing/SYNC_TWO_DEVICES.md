# تجربة المزامنة بين اللابتوب والجوال

**الهدف:** ما أستورده أو أضيفه على اللابتوب يصل كاملًا إلى جوالي، ومعه ملفات المحاضرات.

**متى:** بعد نشر 2.0، وأنا حاضر. حسابي فقط.

## قبل البدء

- [ ] مشروع Supabase غير موقوف (الخطة المجانية توقفه بعد أسبوع دون نشاط).
- [ ] على اللابتوب: الإضافة الرسمية 0.5.0 مثبتة (لا نسخة التجربة المحلية).
- [ ] جهّز ملفًا صغيرًا (أقل من 50 MB) وملفًا أكبر من 50 MB إن توفر.

## الخطوات

| # | الجهاز | الخطوة | المتوقع | النتيجة |
|---|---|---|---|---|
| 1 | اللابتوب | افتح الموقع ← **الإعدادات ← المزامنة**، اكتب بريدك، وافتح رابط الدخول من بريدك **على اللابتوب نفسه** | يظهر أنك مسجّل الدخول | |
| 2 | اللابتوب | **Moodle UCAS ← مزامنة من Moodle** (سجّل دخولك إلى Moodle بنفسك) | مساقاتك وتكليفاتك بمواعيدها | |
| 3 | اللابتوب | **فحص ملفات المساقات** ← استورد 2–3 ملفات | "أُضيف" لكل ملف | |
| 4 | اللابتوب | **مركز الاستيراد** ← ارفع الملف الصغير، ثم الكبير إن توفر | الملفان في المكتبة | |
| 5 | اللابتوب | **الإعدادات ← مزامنة الآن** | رسالة "تمت المزامنة" مع عدد الملفات المرفوعة. للملف الكبير: رسالة باسمه أنه لم يُرفع | |
| 6 | الجوال | افتح الموقع ← **الإعدادات ← المزامنة** بنفس البريد، وافتح الرابط **على الجوال نفسه** | تسجيل الدخول | |
| 7 | الجوال | **مزامنة الآن** | المساقات والتكليفات والمواعيد كما على اللابتوب | |
| 8 | الجوال | افتح ملفًا من المستوردة وملفًا من المرفوعة | يفتح الملف نفسه، لا الاسم فقط | |
| 9 | الجوال | عدّل شيئًا صغيرًا (علّم تكليفًا مكتملًا) ← مزامنة | | |
| 10 | اللابتوب | **مزامنة الآن** | التعديل من الجوال ظاهر | |

## سجّل

- عدد المساقات والتكليفات والملفات على كل جهاز بعد الخطوة 7.
- نص أي رسالة خطأ كما ظهرت.
- الوقت الذي استغرقته المزامنة الأولى على الجوال.

لا ترسل لقطات فيها بريدك أو رقمك الجامعي.
