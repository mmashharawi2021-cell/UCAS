# سياسة الأمن الأساسية (Mandatory)

## المبادئ
- Least Privilege: حساب مدير واحد أو أدوار حسب الحاجة، ولا تضف مستخدمًا/خدمة بلا مبرر.
- Deny by default: لا يُسمح بقراءة/كتابة البيانات إلا بسياسات backend وRLS واضحة.
- Secrets: لا تحفظ مفاتيح API أو PAT أو توكنات أو نسخ قواعد إنتاج في ملفات المكتبة أو Git أو سياق الوكلاء بلا داعٍ.
- Environments: فصل Dev/Staging/Production، مع قيود أقوى للإنتاج.
- Supply chain: تثبيت بإصدارات محددة وLockfiles ومراجعة تراخيص وفحوص تبعيات.
- File uploads: تحقق من الحجم والنوع على الخادم، منع التنفيذ، وفصل Storage عن أذونات المستخدم.
- Login: MFA للمدير، تحديد المحاولات، رسائل خطأ غير كاشفة، مراجعة سجلات.
- Transport: TLS في الإنتاج وعدم تجاوز تحذيرات شهادات.
- Logs: تقليل البيانات الشخصية، وإخفاء الأسرار، وتحديد الاحتفاظ.
- Backups: نسخ احتياطية واستعادة مجربة قبل تغييرات حذف/ترحيل البيانات.

## المعيار المرجعي
OWASP ASVS v5.0.0: https://github.com/OWASP/ASVS

## مراجعة عالية الخطورة
يجب حجب النشر عند: سر مكشوف فعّال، وصول بيانات مستخدم غير مخوّل، API إدارة بلا تحقق خادمي، قابلية رفع ملفات تنفيذية بغير ضبط، أو ثغرة حرجة مؤكدة.

## حدود الفحص
الفحوص النشطة والضغط ممنوعة على مواقع لا نملكها أو لا نملك تفويضًا محددًا بشأنها. الالتزام بسياسة المزود شرط مستقل.
