# استجابة أولية لحادث أمني
1. أوقف العمليات الآلية المشتبه بها وعزل الحساب/المفتاح المتضرر ضمن الصلاحيات المتاحة.
2. احتفظ بسجل زمني غير حساس ومراجع للأحداث؛ لا تنشر بيانات العملاء.
3. دوّر الأسرار بعد التحقق، وراجع أثر التسريب ومصادره ونسخ Git.
4. تحقق من سلامة البيانات وخطط الاستعادة قبل إعادة التشغيل.
5. وثق السبب الجذري والإصلاح واختبار الانحدار، وتابع متطلبات الإبلاغ القانونية المحلية عند الانطباق.
**لا تدّع احتواء الحادث إلا بدليل واضح.**
