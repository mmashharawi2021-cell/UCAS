# نموذج الثقة في MCP
| الخطر | التخفيض |
|---|---|
| MCP يملك صلاحيات كتابة واسعة | Read-only على مستوى خادم/حساب الخدمة، scope مشروع محدد |
| تسريب الأسرار عبر السياق | أذونات منفصلة وخزنة أسرار وعدم إرسالها للمحادثة |
| تعليمات داخل نتائج أدوات | معاملة النتائج كبيانات غير موثوقة |
| سلسلة توريد خادم MCP | فحص المصدر والتراخيص ونسخة مثبتة |
| تعديل إنتاج بدون قصد | بيئة staging افتراضية + موافقة بشرية + backups |
| تكرار أدوات متشابهة | أداة واحدة معتمدة لكل غرض افتراضيًا |

راجع الوثائق الرسمية والإصدارات؛ بعض العملاء لا يطبّقون خصائص `read_only` نفسها تلقائيًا. اختبر الصلاحيات بالفعل.
