# معايير الواجهة
- وحدات تصميم قابلة لإعادة الاستخدام: ألوان وظيفية، مسافات، أحجام، Typographic scale.
- حالات التطبيق لكل شاشة: loading/empty/error/permission/success.
- دعم الهاتف واللوحي والحاسوب مع استخدام Grid مناسب.
- تقليل الحزم والخطوط الخارجية وحفظ الأداء.
- استخدام نصوص عربية طبيعية مع المصطلحات الإنجليزية عند الضرورة.
- لا تستبدل وظائف الوصول بالتجميل؛ افحص الاستخدام بلوحة المفاتيح.
