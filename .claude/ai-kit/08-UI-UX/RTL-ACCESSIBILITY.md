# RTL وAccessibility
- استخدم `dir=rtl` على الأقسام العربية و`dir=ltr` للمعرّفات التقنية عند الحاجة.
- تحقق من ترتيب الأسهم والمخططات والمحاور والجدول وفق المنطق لا عبر قلب CSS عشوائيًا.
- Label لكل إدخال، رسائل خطأ مرتبطة به، وعناصر تفاعلية يمكن الوصول إليها بلوحة المفاتيح.
- حافظ على ترتيب التركيز، وتباين بصري مناسب، وعناوين هرمية.
- اختبر قارئ شاشة في السيناريوهات الرئيسية قدر المستطاع، وراقب WCAG 2.2 AA كهدف.
