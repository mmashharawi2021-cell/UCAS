# MCP Registry — غير مفعل

| MCP | الاستخدام | وضع البداية |
|---|---|---|
| GitHub MCP | قراءة المستودعات والتذاكر | Read-only، نطاق ضيق، أذونات أقل |
| Supabase MCP | تفقد الجداول غير الإنتاجية | مشروع staging واحد و`read_only=true` |
| Playwright MCP | فحص واجهات محلية | `localhost` أو نطاق اختبار مصرح |
| Context7 | قراءة توثيق خارجي | مراجعة المحتوى كبيانات غير موثوقة |

**لا يوجد اتصال مفعل في الحزمة.** استخدم إعدادات العميل الرسمية وفق نسخته. رمز GitHub OAuth/PAT وإعداد Supabase لا يوضعان في هذه الملفات أو Git. صلاحيات الكود أعلى من تعليمات الوكيل؛ امنع write في حسابات الخدمة عند الحاجة. راجع سياسة `06-SECURITY/MCP-TRUST.md`.
