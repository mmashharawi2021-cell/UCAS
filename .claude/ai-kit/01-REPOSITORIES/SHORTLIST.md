# الاختيارات المبدئية (ليست إلزامية)
- تطوير واجهة تفاعلية: React + Vite + Tailwind؛ shadcn/ui عند الحاجة لمكونات لوحة الإدارة.
- بيانات مع مدير واحد: Supabase مع RLS واختبارات قواعد بيانات.
- GIS اختياري: MapLibre لعرض الخريطة، PostGIS فقط لاستعلامات حقيقية.
- تحقق المدخلات: Zod على العميل **مع تحقق خادمي مستقل**.
- اختبار الواجهة والأداء: Playwright وLighthouse؛ k6 فقط لبيئة مصرح بها.
- وكيل تطوير: Goose أو عميل المستخدم الحالي، مع تعليمات `AGENTS.md`.
- لا تشغّل Mastra / LangGraph ولا تثبّت Skills خارجية إلا عند حاجة محددة وتقييمها.
