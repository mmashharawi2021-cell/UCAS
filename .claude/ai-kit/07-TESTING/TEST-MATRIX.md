# مصفوفة الاختبارات
| الصنف | أمثلة | التنفيذ |
|---|---|---|
| Unit | تحقق بيانات/دوال/حالات | محلي وCI |
| API/DB | حدود إدخال وRLS وحقوق المستخدمين | Staging ببيانات اصطناعية |
| E2E | دخول مدير/إدارة محتوى/فشل رفع | Playwright |
| Security | تسريب أسرار/تبعية معرضة/مراجعة إعداد | Gitleaks, OSV, Semgrep |
| DAST | فحص سلبي للتطبيق المملوك | مراجعة وتفويض، ZAP Baseline |
| Performance | p95/errors/resource saturation | k6 لبيئة مصرح بها |
| GIS | CRS/طبقات/حجم/نسب مصدر الخرائط | يدوي وآلي عند الإمكان |
| RTL/a11y | اتجاه/مفاتيح/التباين | Playwright + axe-core عند الإمكان |

سجل دائمًا المدة والنسخة والبيئة والنتيجة والأداة، واحذف أي بيانات حساسة من تقارير الاختبار.
