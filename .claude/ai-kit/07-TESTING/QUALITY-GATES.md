# بوابات الجودة قبل الدمج والنشر

| البوابة | الحد الأدنى | عند الفشل |
|---|---|---|
| Source & Dependency | فحص أسرار وتبعيات وكود | أوقف دمج المخاطر العالية/الحرجة |
| Unit/Integration | اختبارات فعالة مع تغطية المسارات الحرجة | أصلح أو وثق عائقًا حرجًا |
| Roles/RLS | منع الوصول غير المصرح للقراءة والكتابة | حجب النشر |
| E2E | تسجيل مدير + عمليات CRUD الرئيسية + حالات الخطأ | حجب النشر عند كسر سيناريو أساسي |
| Accessibility | لوحة مفاتيح وتسميات وتباين رئيسي | إصلاح قبل إطلاق عام بحسب الشدة |
| Performance | ميزانية محددة بـ p95 وerror rate وفق نتائج فعلية | تحقيق ثم قرار واضح |
| Release | موافقة مالك المشروع وrollback | لا نشر |

**تعريف الحالات:** `PASS`, `FAIL`, `NOT_RUN`, `NOT_APPLICABLE`. `NOT_RUN` ليست `PASS`.

**قيم بداية مقترحة فقط** وليست ادعاء قدرة: p95 لعمليات القراءة الأساسية <= 1s في بيئة staging مضبوطة؛ نسبة أخطاء HTTP 5xx < 1% أثناء سيناريو متفق عليه. تُعدل الأهداف حسب طبيعة الموقع والبيئة.
