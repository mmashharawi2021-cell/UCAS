# عقد تسليم الأدوار

**كل دور يعيد تقريرًا بهذا الترتيب:**
1. `Objective`: هدف المهمة وتذكرة التتبع.
2. `Scope`: الملفات والمكونات المسموح بها.
3. `Actions`: ما تغيّر فعلًا (ليس ما تم اقتراحه).
4. `Evidence`: أوامر اختبار محلية ونتائج فعلية أو `NOT_RUN`.
5. `Risk`: الثغرات والقيود والمخاطر المتبقية.
6. `Handoff`: ما يحتاج مراجعة/موافقة، وطريقة الرجوع.

**بوابات الاعتماد:** لا يعتبر الوكيل المهمة ناجحة لمجرد أن النموذج كتب 'نجح'. يلزم دليل اختبار أو مراجعة بشرية مناسبة. لا تتشارك الوكلاء أسرارًا أو صلاحيات خارج النطاق. الحسم الأخير للنشر والتكلفة وحذف بيانات الإنتاج للبشر.
