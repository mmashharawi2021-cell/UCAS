# stack-selection

## خطوات
1. اقرأ `01-REPOSITORIES/SELECTION-POLICY.md` من جذر المكتبة.
2. اربط كل احتياج بمستودع واحد أساسي، واذكر بديلًا واحدًا عند الضرورة.
3. تحقق من الرخصة والحالة والتحديث والدعم عند القدرة على الوصول للمصادر؛ لا تخمن.
4. راجع الوظائف المتداخلة والتكاليف الخفية للمستودعات والخدمات.
5. وثق ADR واضحًا وطلب موافقة قبل تنزيل أداة.

## التسليم
جدول requirement/choice/rationale/risk/cost/checks.

## قيود عامة
- اقرأ فقط الملفات اللازمة للمهمة.
- التزم بـ `AGENTS.md` في جذر المشروع وسياسات `06-SECURITY`.
- لا تدّع تشغيل أداة أو اجتياز اختبار لم يحدث.
- تأكيد بشري قبل تثبيت أو نشر أو الوصول لإنتاج.
