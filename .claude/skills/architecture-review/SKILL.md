# architecture-review

## خطوات
1. حدد حدود العميل والخادم والتخزين وعمليات المصادقة؛ ارسم مخطط تدفق بيانات.
2. تحقق من فصل البيئات ومناطق الثقة وإدارة الفشل والتوسع والترقية.
3. راجع تكلفة الخدمات المجانية وحدودها المتغيرة.
4. اقترح تغييرًا مرحليًا مع rollback وADR.
5. اطلب مراجعة Security للقرارات ذات المخاطر العالية.

## التسليم
قائمة المخاطر بالمستوى والأثر، قرارات ADR، حالات اختبار للحدود.

## قيود عامة
- اقرأ فقط الملفات اللازمة للمهمة.
- التزم بـ `AGENTS.md` في جذر المشروع وسياسات `06-SECURITY`.
- لا تدّع تشغيل أداة أو اجتياز اختبار لم يحدث.
- تأكيد بشري قبل تثبيت أو نشر أو الوصول لإنتاج.
